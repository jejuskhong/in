# 💰 대한민국 은행 예·적금 세전/세후 이자 계산기 & 커뮤니티

대한민국 세법(15.4% 일반과세, 1.4% 세금우대, 비과세) 및 금융권 10원 단위 절사 기준을 반영한 **웹 기반 은행 이자 계산기**와 **Google Firebase Firestore 실시간 댓글 커뮤니티**입니다.

일반 사용자 화면에서는 깔끔한 계산기와 댓글 기능만 제공되며, **DB 연동 설정 및 댓글 강제 삭제는 관리자 전용 페이지(`admin.html`)**에서만 안전하게 관리할 수 있습니다.

---

## ✨ 주요 기능

### 1. 예·적금 세전/세후 이자 정밀 계산기 (`index.html`)
- **정기예금 (목돈 굴리기)**: 단리 및 월복리 계산
- **정기적금 (목돈 모으기)**: 월 적립식 단리 및 월복리 계산
- **과세 체계 완벽 지원**:
  - **일반과세 (15.4%)**: 이자소득세 14% + 지방소득세 1.4%
  - **세금우대 / 저율과세 (1.4%)**: 신협·새마을금고·농협 등 상호금융 예탁금 농어촌특별세 반영
  - **비과세 (0%)**: 청년도약계좌, ISA 만기, 만 65세 이상 비과세종합저축
  - **직접입력 (%)**: 사용자 정의 세율 설정
- **편의 기능**:
  - 빠른 금액/기간/이율 증감 버튼 (+10만, +100만, +1,000만, +5,000만 원 / 6, 12, 24, 36개월 등)
  - 한글 금액 실시간 표시 (예: 1억 2,500만 원)
  - 월별 회차별 원금 및 이자 발생 스케줄표 (접이식)
  - 계산 결과 원클릭 클립보드 복사 (카톡/메모장 공유용)

### 2. 사용자별 금융 후기 & 실시간 댓글
- **닉네임 & 자동 컬러 아바타**: 닉네임 기반 고유 프로필 아바타 생성
- **비밀번호 기반 삭제**: 본인이 작성한 댓글만 안전하게 삭제 가능
- **계산 결과 첨부 공유**: 현재 계산한 예·적금 조건(금액, 금리, 세후이자 등)을 뱃지 형태로 댓글에 함께 게시
- **실시간 동기화**: Google Cloud Firestore `onSnapshot` 기반으로 새로고침 없이 즉시 댓글과 추천수가 반영

### 3. 관리자 전용 대시보드 (`admin.html`)
- **보안 인증**: 관리자 비밀번호 입력 후 접속 (기본값: `admin1234`, 관리자 페이지에서 변경 가능)
- **Firebase DB 연동 설정**: 일반 사용자에게 노출되지 않고 관리자 페이지에서만 클라우드 DB 키 설정 및 로컬 모드 전환 관리
- **댓글 모더레이션**: 사용자 비밀번호 없이 부적절한 광고/악성 댓글을 관리자 권한으로 강제 삭제

## 🚀 빠른 시작 (로컬 실행)

1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 웹 브라우저(Chrome, Edge, Whale 등)로 열어 계산기 및 댓글 기능을 사용합니다.
3. `admin.html`을 열어 관리자 로그인(기본 비밀번호: `admin1234`) 후 Firebase DB를 연동할 수 있습니다.

## 🔥 Firebase Firestore 연동 가이드 (관리자용)

1. [Firebase Console](https://console.firebase.google.com/) 접속 후 새 프로젝트 생성
2. 좌측 메뉴 [빌드] ➔ **Firestore Database** 만들기 (테스트 모드 선택)
3. [프로젝트 설정 ⚙️] ➔ [내 앱] ➔ **웹 앱(`</>`)** 추가
4. **관리자 페이지(`admin.html`)**에 로그인 후 발급된 `apiKey`, `projectId`, `appId`를 입력하여 저장하면 메인 페이지에 실시간 클라우드 DB가 즉시 적용됩니다.
