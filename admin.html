📌 Firebase 설정값 등록 방법:
  1. Firebase Console에서 프로젝트 생성 후 Firestore Database 활성화 (테스트 모드)
  2. [프로젝트 설정 ⚙️] ➔ [내 앱] ➔ 웹 앱(</>) 추가 후 나오는 firebaseConfig 키 입력
